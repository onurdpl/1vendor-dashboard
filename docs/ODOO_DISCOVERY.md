# Odoo Discovery

> Historical retired-integration notes. This provider is no longer connected or supported.
> Setup commands, credentials, probes and execution paths below are forensic history only,
> not current operational instructions. The executable integration has been removed.

## Status

Odoo discovery is inactive and deprecated.

Odoo will not be used by this project. The deployed application must not expose Odoo probe routes, production probe instructions, or static probe-token execution paths for Odoo.

Historical Odoo service/client files and database fields may remain temporarily for compatibility and controlled cleanup, but they are not active runtime integration points.
