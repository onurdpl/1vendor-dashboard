## Objective and approved boundary

Package 3 makes the selected Vendor the canonical context for Admin Vendor Workspace reads and for Vendor-facing data shown there. An Admin may select an existing Vendor without individual Vendor membership; Vendor accounts retain their membership restrictions. Selection must be verified before Vendor Workspace content becomes active, and a context switch must not display the previous Vendor's records. Package 3 does not expand financial or operational write authority.

The implemented scope is F01/F02 Dashboard and Vendor Inbox isolation, F03 Support/Shipping Config/Automation/Signals reads, F04 Global Admin Vendor Selector and standalone Directory pagination correction, and F05 exact-ID Vendor context verification. The implementation history is [PR #25](https://github.com/onurdpl/1vendor-dashboard/pull/25) through [PR #32](https://github.com/onurdpl/1vendor-dashboard/pull/32), all merged into `main`.
